# 09 · 自动化与网页界面

v2.1 新增。两件事：**少让你敲命令**，以及**把结果画出来**。

---

## 一、自动化：一条命令跑完

```bash
python -m hk auto
```

它依次做四件事：

1. **自动检测**你的硬件（CPU、显卡、内存、存储接口、机型）
2. **自动判定**能不能装、装到哪个版本、卡在哪
3. **生成安装计划**（按机型裁剪，笔记本/台式机/服务器各不相同）
4. **写一份 Markdown 报告**到 `reports/`

报告长这样：

```
# 黑苹果可行性报告
## 检测到的硬件
| 系统 | Linux / x86_64 |
| CPU  | i5-10400 |
...
## 结论
**可以装，建议 macOS Tahoe；范围 12.2 – 26**
## 逐项检查
| ✅ | 显卡｜RX 6600 | Navi 23 免驱 | |
## 安装计划
### 1. 备份，把目标硬盘腾出来
...
## 环境体检
```

可以直接发给别人看，或者打印出来照着做。

## 二、分开用也行

自动化是四个命令串起来的，想单跑哪步都行。

### `detect` 自动检测

```bash
python -m hk detect
```

```
自动检测结果
  系统    Windows / AMD64
  CPU    Intel(R) Core(TM) i5-10210U CPU @ 1.60GHz
  显卡    Intel UHD Graphics 620
  内存    16 GB
  存储    nvme
  机型    laptop
```

各平台怎么读：

| 平台 | 读取方式 |
|---|---|
| Windows | PowerShell CIM 查询（不用已废弃的 wmic） |
| Linux | `/proc`、`/sys`、`lspci` |
| macOS | `system_profiler` |

读不到的字段会留空并说明原因（比如「没有 lspci，显卡型号无法读取」），
不会让你对着一屏空白猜。

### `doctor` 环境体检

```bash
python -m hk doctor
```

检查 Python 版本、路径有没有中文、磁盘够不够、工具文件在不在、能不能连 GitHub。
这些正是「会让你白忙一场」的东西。

## 三、网页界面

```bash
python -m hk serve
```

打开 <http://127.0.0.1:8765>。

### 三个主题

| 主题 | 什么时候用 |
|---|---|
| **白色** | 白天、亮环境，打印截图好看 |
| **黑色** | 晚上，长时间看不刺眼 |
| **科技风** | 动态渐变背景 + 玻璃卡片，演示用 |

右上角切换，选择会记住（存在浏览器 localStorage）。

### 能做什么

- 填硬件 → 点「开始判定」→ 看到红绿灯
- 点「自动检测」→ 直接把本机硬件读进表单（Windows 上最省事）
- 点「生成安装计划」→ 分步骤展开

### 安全

- 默认只监听 `127.0.0.1`，同网段的人扫不到
- 页面是单文件静态资源，**不加载任何 CDN**，断网也能用
- 如果非要 `--host 0.0.0.0` 给别的机器看，启动时会警告

## 四、接口

界面和命令行共用一套逻辑，所以接口也能直接用：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/detect` | 自动检测硬件 |
| POST | `/api/check` | 判定，body 同 CLI 参数 |
| POST | `/api/plan` | 生成计划 |
| GET | `/api/matrix` | 兼容性表 |
| GET | `/api/troubleshoot?q=黑屏` | 按现象查 |
| GET | `/api/bios?vendor=lenovo` | BIOS 清单 |
| GET | `/api/doctor` | 环境体检 |

```bash
curl -X POST http://127.0.0.1:8765/api/check \
  -H "Content-Type: application/json" \
  -d '{"cpu":"i5-10400","gpus":["RX 6600"],"storage":"sata","platform":"desktop"}'
```

---

## 五、它还是不做的事

- **不替你装系统**。能检测、能判定、能出计划，最后那几步要你亲手做。
- **不改你的 BIOS**。有些主板能通过厂商工具改，但那风险太高，不该自动化。
- **不保证结果**。判据是「macOS 有没有原生驱动」，覆盖不到你机器上所有奇怪情况。
