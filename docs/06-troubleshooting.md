# 06 · 故障速查

按**现象**查，不要按"错误代码"查 —— 黑苹果的报错信息大部分没有直接含义，现象才是线索。

---

## 第一步：打开详细模式（-v）

默认的苹果 logo 会遮住所有信息，出问题第一件事就是让它把日志打出来。

**方法**：在 OpenCore 菜单里选中启动项，按 `空格` 显示隐藏选项，选 `Reset NVRAM`；或者直接改 `config.plist`：

```
NVRAM → Add → 7C436110-AB2A-4BBB-A880-FE41995C9F82 → boot-args
值填：-v debug=0x100 keepsyms=1
```

这样开机会滚代码。**卡住时拍下最后 3–5 行**，这是排查的唯一依据。

常见的有用 boot-args：

| 参数 | 用途 |
|---|---|
| `-v` | 显示启动日志 |
| `debug=0x100` | 内核崩溃时不自动重启，停在错误页 |
| `keepsyms=1` | 崩溃日志里显示函数名，方便定位 |
| `-x` | 安全模式，跳过第三方 kext |
| `npci=0x2000` / `npci=0x3000` | 卡在 `PCI Configuration Begin` 时用 |
| `igfxonln=1` | 强制核显上线（笔记本内屏不亮时试） |
| `-wegnoegpu` | 禁用独立显卡 |
| `-igfxvesa` | 强制核显用 VESA 模式（不加载加速，但能亮） |
| `alcid=11` | 声卡 layout-id，数字按你的声卡换 |
| `cpus=1` | 只用单核，排查多核问题 |
| `-no_compat_check` | 绕过"机型不支持"检查 |

## A. 卡在苹果 logo，无进度条

进度条完全不动，说明卡在早期初始化。

**排查顺序**：

1. **先等 5 分钟**。有些机器第一次启动很慢（尤其是服务器、大内存机器）。
2. 加 `-v` 看卡在哪一行。常见卡点：
   - `IOConsoleUsers: gIOScreenLockState 3` → 显卡已加载，但显示没切过来 → 换显示接口（HDMI 换 DP，或反过来）
   - `AppleACPICPU` → ACPI 问题 → 检查 SSDT
   - `waiting for root device` → 硬盘控制器问题 → 见 [F](#f-磁盘工具看不到硬盘)
3. **换 USB 口**。优先插主板后置的 USB 2.0 口，别用前置、别用 USB Hub。
4. **关掉 BIOS 里的 XMP**（内存超频偶尔会导致卡住）。
5. 用 `-x` 安全模式启动，能进说明是某个 kext 的问题，逐个排除。

---

## B. 进度条卡住

进度条走到某个固定位置就不动了。

| 卡在哪 | 原因 | 处理 |
|---|---|---|
| 1/3 左右 | 显卡驱动加载失败 | 用 `-igfxvesa` 只求点亮，装完再修 |
| 一半左右 | 存储 / USB 控制器 | 检查 VMD、USB 映射 |
| 最后 1/10 很久 | **正常现象**，在解压安装包 | 等，10–30 分钟都可能 |

> 进度条在最后卡住 20 分钟以上且硬盘灯不闪，才是真卡住。

---

## C. 进度条走完黑屏或花屏

系统其实已经启动了，只是显示没切过来。

1. **换接口**：DP → HDMI，或 HDMI → DP。独显上多个口，逐个试。
2. **换线**：劣质 HDMI 线会导致 EDID 读不到。
3. 笔记本内屏黑、外接屏亮 → framebuffer 配置问题，见 [03 全能本](03-allround-laptop.md#5-修内置屏最常见的问题)。
4. 花屏/条纹 → 显存识别有问题，试试 `slide=0` 或换 `AAPL,ig-platform-id`。
5. 核显被识别成"显示器未连接" → 加 `igfxonln=1`。

---

## D. 出现禁行符号

那个圆圈加斜杠的标志，意思是"找不到可启动的根设备"。

1. **最常见：硬盘控制器没驱动**
   - Intel VMD / RST 没关 → 进 BIOS 关掉
   - 硬盘接在 RAID 卡上 → 换到板载 SATA
   - NVMe 是杂牌主控 → 试试加 `NVMeFix.kext`
2. **USB 端口问题**：U 盘插在 USB 3.x 口上但驱动没起来 → 换 USB 2.0 口
3. **EFI 放错位置**：U 盘根目录必须有 `EFI/BOOT/BOOTx64.efi`
4. 少数情况是 `apfs` 模块缺失 → 确认 `OpenRuntime.efi` 和 `OpenCanopy.efi` 在 `Drivers/` 里

---

## E. 重启循环

开机就重启，看不到任何错误。

1. 加 `debug=0x100 keepsyms=1`，让它在崩溃时停下来显示原因
2. **内存**：拔到只剩一根，或关掉 XMP
3. **显卡**：`-wegnoegpu` 禁用独显试试
4. **kext 冲突**：`-x` 安全模式，能进就好办
5. 服务器双路：参考 [04 服务器](04-server.md) 的双路 ACPI 部分

---

## F. 磁盘工具看不到硬盘

这是出现频率最高的问题之一。

| 检查项 | 操作 |
|---|---|
| SATA 模式 | BIOS 里确认是 **AHCI**，不是 RAID/RST/VMD |
| Intel VMD | BIOS 里有就关掉 |
| 阵列卡 | 系统盘不要接在 PERC/RAID 卡上，用板载 SATA |
| 硬盘格式 | 全新盘应该是"未初始化"，磁盘工具里显示为未抹掉的设备 |
| 磁盘工具视图 | 左上角点「显示所有设备」，不然只看得到分区看不到盘 |
| NVMe 兼容性 | 少数主控（如某些国产盘）需要 `NVMeFix.kext` 或者根本不支持 |

> 如果 BIOS 里根本没有 AHCI 选项，这台机器基本可以放弃。

---

## G. 无法安装在此电脑上

安装器拒绝继续，提示这个 macOS 版本不支持你的机型。

说明 **SMBIOS 选的机型太老/太新**，和你要装的系统对不上。

**处理**：重跑 OpCore-Simplify，让它根据你的硬件重新推荐 SMBIOS；或者在 `config.plist` 的 `PlatformInfo → Generic → SystemProductName` 换一个同代机型（比如 `iMac19,1` 换成 `iMac20,1`）。

临时绕过：加 `-no_compat_check` boot-arg，但不建议长期用（会影响系统更新和部分功能）。

---

## H. 装完进不去系统

第一次重启后，选硬盘上的 macOS 启动，卡住。

1. **还是从 U 盘引导**，但在菜单里选**硬盘上的 macOS**（而不是 U 盘里的）。这样可以区分是"EFI 有问题"还是"系统有问题"。
2. 如果 U 盘引导能进、硬盘引导不能进 → **硬盘上的 EFI 没放对**，重新拷贝一次。
3. 如果都进不去 → 加 `-v` 看卡点，按 [A](#a-卡在苹果-logo无进度条) 排查。

---

## I. 没有声音

声卡驱动基本靠 `AppleALC` + 正确的 `layout-id`。

1. 查你的声卡型号：`系统信息 → 硬件 → 音频`，或 Windows 下用 AIDA64 看
2. 去 [AppleALC 支持列表](https://github.com/acidanthera/AppleALC/wiki/Supported-codecs) 找对应的 layout 编号
3. 改 boot-arg：`alcid=你的编号`（最快，不用改 plist）
4. 重启，在「系统设置 → 声音」里选输出设备

常见对应：

| 声卡 | 常用 layout-id |
|---|---|
| ALC892 | 1、2、3、7 |
| ALC897 | 11、69 |
| ALC1200 | 11、69 |
| ALC1220 | 1、7、11 |
| ALC256（笔记本） | 11、13、21 |
| ALC295（笔记本） | 3、13、28 |

都不行的话：**买个 USB 声卡**（十几块），立刻解决。

---

## J. 网络不通

| 网卡 | 需要的 kext |
|---|---|
| Intel I219 / I225 | `IntelMausi.kext` |
| Intel I225-V 部分批次 | 需要额外补丁，Ventura 后基本可用 |
| Realtek RTL8111/8168 | `RealtekRTL8111.kext` |
| Realtek RTL8125（2.5G） | `LucyRTL8125Ethernet.kext` |
| 无线 Intel AX200/AX201 | `AirportItlwm.kext`（按系统版本选对应的） |
| 无线 Broadcom BCM94360 | 免驱 |

无线没驱动时，**插网线装系统**是最省事的。

---

## K. 分辨率不对

只显示 1024×768 或 1280×800，说明显卡驱动没生效，系统在用 VESA 兜底。

1. 确认 `WhateverGreen.kext` 已加载
2. 核显要设对 `AAPL,ig-platform-id`
3. 独显要确认没有被禁用
4. **不是驱动问题的情况**：显示器通过转接头连接，EDID 读不到 → 直连试试

---

## L. USB 键鼠失灵

装完系统后键鼠不动，或者要插拔才认。

根本原因是 **USB 端口没有映射**，macOS 只认前 15 个端口。

**解决**：用 `USBToolBox`（Windows 下能跑）扫描所有端口，生成 `USBPorts.kext`，替换掉原来的 `USBInjectAll`。

```bat
# Windows 下
USBToolBox.exe
# 选 Discover Ports → 逐个插拔 USB 设备 → 生成 kext
```

这一步台式机必做，笔记本也建议做（顺便修睡眠）。

---

## M. 睡眠问题

见 [07 安装后优化](07-post-install.md#7-睡眠)。核心思路：

1. USB 映射（承接上面 L）
2. 关掉网卡唤醒
3. RTC 补丁
4. 实在修不好，用「防止电脑自动进入睡眠」的软件顶一下

---

## 求助时该提供什么

去论坛或 issue 提问，把这几样贴上，能省掉一半来回：

1. 完整硬件（CPU、主板、显卡、网卡、硬盘型号）
2. macOS 版本 + OpenCore 版本
3. `-v` 卡住时**最后 5 行**的截图
4. 你的 `config.plist`（**记得删掉序列号**）
5. 已经试过哪些方案

> ⚠️ 分享 EFI 前一定要删掉 `PlatformInfo` 里的 `SystemSerialNumber`、`MLB`、`SystemUUID` —— 这些等于你的 Apple ID 身份，泄露了别人能用你的账号。
