# 03 · 全能本 / 游戏本（标压 + 独显）

**难度 ★★★★★ ｜ 推荐度：低 ｜ 说实话：这类机器大多数装不了**

先给结论，省你几个小时：

> **2020 年以后的全能本和游戏本，90% 以上装不了 macOS。**
> 能装的那 10%，体验也通常不如一台两千块的二手办公本。

这一篇主要帮你**快速判断你的机器是那 90% 还是 10%**，以及如果真的是那 10%，怎么装。

> 代表机型：联想拯救者 Y9000P/R9000P、ROG 幻 16 / 枪神、华硕天选、惠普暗影精灵、机械革命、微星 GE/GP 系列、戴尔 G15、雷蛇灵刃

---

## 一、为什么这么难

一台典型的游戏本是「i7-12700H + RTX 3060 + 双显卡切换」。三个硬件各自都有问题：

### 1. 独显（RTX）→ 完全无解

NVIDIA 从 RTX 20 系开始就再没有 macOS 驱动。不是"难搞"，是**根本没有驱动存在**。

### 2. 核显 → 可能也不支持

11 代酷睿（Tiger Lake）及以后的核显，macOS 同样没有驱动。

所以「12 代 i7 + RTX 3060」的组合是：**独显无解 + 核显也无解 = 没有能输出画面的 GPU**。

### 3. 就算核显能用，还要过"独显直连"这一关

游戏本有两种显卡模式：

| 模式 | 谁在输出画面 | 黑苹果能不能用 |
|---|---|---|
| **混合模式（Optimus / Hybrid）** | 核显输出，独显算 | ✅ 核显能驱动就 OK |
| **独显直连（dGPU / Discrete）** | 独显直接连屏幕 | ❌ 核显根本没接屏幕，装上也黑屏 |

很多游戏本**默认就是独显直连**，或者需要在厂商软件里手动切回混合模式。

---

## 二、30 秒判断流程

按顺序回答，一旦命中「❌」就停：

```
① 你的独显是 AMD 的吗？
   ├─ 是（很少见，如某些老款 RX 6600M 机型）→ 大概率能装，跳到第四节
   └─ 不是（NVIDIA）→ 继续

② 你的核显是 11 代酷睿（Tiger Lake）或更新吗？
   ├─ 是 → ❌ 装不了，没有可用 GPU
   └─ 不是（10 代及更早）→ 继续

③ BIOS / 厂商控制中心里，能不能切到「混合模式 / 集显模式」？
   ├─ 能，且有选项 → ✅ 有希望，继续往下看
   └─ 不能，或只有独显直连 → ❌ 装不了，核显没有输出通道

④ 核显是否被 BIOS 屏蔽（有些游戏本直接禁用了核显）？
   ├─ 是 → ❌ 装不了
   └─ 否 → ✅ 可以尝试
```

### 判定结果对照表

| 你的配置 | 结果 |
|---|---|
| 8–10 代 H/U + GTX 10 系 + 可切混合模式 | ⚠️ 能装，用核显，独显废掉 |
| 8–10 代 H/U + RTX 20/30 系 + 可切混合模式 | ⚠️ 能装，用核显，独显废掉 |
| 11 代及以后 + 任何 N 卡 | ❌ 装不了 |
| 任何代 + 独显直连且无法切回 | ❌ 装不了 |
| 任何代 + AMD 独显（RX 6600M 等） | ✅ 有希望 |

> 怎么查自己是什么显卡模式：Windows 里打开「任务管理器 → 性能」，看 GPU 0 和 GPU 1 哪个在工作；或者装 `GPU-Z` 看是否支持 Optimus。最直接的是进 BIOS 找 `Graphics Configuration` / `Display Mode` / `MUX Switch`。

## 三、如果命中「⚠️ 能装」，你要接受什么

假设你的机器是「i7-9750H + RTX 2060」，切到混合模式，核显 UHD630 输出。装上之后：

| 项目 | 情况 |
|---|---|
| 图形性能 | 只有 UHD630 的水平，**打游戏不可能**，剪 4K 会卡 |
| 独显 | 被禁用，等于不存在，还费电 |
| 屏幕高刷 | 可能只能 60Hz，或者需要额外修 framebuffer |
| 亮度调节 | 多数要修 `SSDT-PNLF`，修不好就固定亮度 |
| 键盘背光 | 通常不工作 |
| 风扇控制 | 不工作，风扇可能一直转，也可能不转（危险） |
| 续航 | 明显变差 |
| 睡眠 | 大概率睡死 |
| 触控板 | I2C 触摸板，需要 `VoodooI2C`，能修 |
| 雷电口 | 半残 |

**换句话说：你会得到一台"能开机的、性能不如核显轻薄本的" Mac。**

## 四、真的要装的话，步骤

### 1. 先在 BIOS 里切混合模式

不同品牌位置不同：

| 品牌 | 位置 |
|---|---|
| 联想拯救者 | BIOS → `Configuration` → `Graphic Device` → 选 `Switchable Graphics`（有些机型要用 Lenovo Vantage 的「混合模式」） |
| ROG / 天选 | BIOS → `Advanced` → `Graphics Configuration` → `Hybrid`；或 Armoury Crate 里切「标准模式」 |
| 暗影精灵 | BIOS → `Advanced` → `Video Configuration`；或 OMEN Gaming Hub 切「混合模式」 |
| 微星 | BIOS → `Advanced` → `Integrated Graphics` → `Enabled`（需先解锁高级菜单） |
| 机械革命 | 多数**没有**这个选项，基本无解 |

### 2. 关掉 Secure Boot 和 VMD

同 [01 办公笔记本](01-office-laptop.md)，游戏本的 VMD/RST 问题更常见。

### 3. 用 OpCore 生成 EFI（关键在禁用独显）

跑硬件报告后，确认：

- 核显是 **Supported**
- 独显是 **Not supported**，并且 OpCore 给它加了 `disable-gpu` 属性

如果 OpCore 没自动禁，在 `config.plist` 的 `DeviceProperties` 里给独显的 PCI 路径加：

```
disable-gpu = 01000000 (Data)
```

### 4. 装系统

流程同 [01](01-office-laptop.md)。第一次进系统建议接**外接显示器**，因为内置屏可能需要修 framebuffer 才能亮。

### 5. 修内置屏（最常见的问题）

内置屏是 eDP 接口，需要用 `WhateverGreen` 的 `framebuffer-patch-enable` 配合正确的 `AAPL,ig-platform-id`。

排查顺序：

1. 外接屏能亮、内置屏黑 → framebuffer 配置问题
2. 内置屏亮但分辨率错 → `AAPL,ig-platform-id` 选错
3. 花屏/闪烁 → 尝试不同的 platform-id

这部分没有通用答案，需要去论坛按你的**具体核显型号 + 屏幕分辨率**找现成配置。

## 五、更值得考虑的替代方案

如果你的目标是「在 Windows 游戏本上用 macOS」，下面这些方案成功率更高、体验更好：

### 方案 1：虚拟机（最推荐，几乎零风险）

- **VMware Workstation Pro**（现在个人免费）+ `unlocker` 补丁
- 或 **VirtualBox**（性能差一些）
- 优点：不破坏现有系统，随时快照回滚，失败了删掉就行
- 缺点：没有硬件加速（只能用 CPU 渲染），做开发、测试、跑命令完全够用，剪视频不行

### 方案 2：买一台二手 Mac mini

2018 款 i3 的 Mac mini 二手约 1500–2000 元，性能比你折腾半天装出来的核显黑苹果**强得多**，而且零风险、能升级系统、能用全部苹果生态功能。

如果你需要的是"一台能用的 Mac"，这是性价比最高的路。

### 方案 3：台式机黑苹果 + 游戏本分工

游戏本继续打游戏，另装一台 A 卡台式机跑 macOS。见 [02 游戏电脑](02-gaming-pc.md)。

## 六、如果你已经装成功了

欢迎在 issue 里分享你的机型配置，帮到后面的人。记录时建议包含：

- 完整型号（如 `Legion Y7000P 2020H`）
- CPU + 核显型号
- 独显型号 + 是否禁用
- 屏幕分辨率 + 是否内屏点亮
- macOS 版本
- 哪些功能不可用

---

**结论**：这类机器装黑苹果，投入产出比是四类里最差的。除非你纯粹是为了折腾的乐趣，否则建议直接走虚拟机或买 Mac mini。
